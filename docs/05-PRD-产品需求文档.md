## 1. 背景与目标

### 1.1 问题定义

B2B 销售在「见客户前准备 → 会中异议应对 → 会后跟进」三个环节高度依赖个人经验：新人成长慢（3 个月+）、异议处理是丢单首因（38%）、跟进邮件日均耗时 1.4 小时。静态话术手册因无法匹配具体场景（行业 × 角色 × 阶段 × 异议）而失效。

### 1.2 产品目标

| 目标类型 | 指标 | V1.0 目标值 |
|---------|------|:---:|
| **北极星指标** | 周活跃用户人均周生成次数 | ≥ 5 |
| 价值指标 | 话术采纳率（复制或收藏 / 展示） | ≥ 40% |
| 性能指标 | 生成 P95 耗时 | < 15s |
| 留存指标 | 次周留存率 | ≥ 40% |

### 1.3 不做什么

见 [02-需求分析与优先级 §4.2](./02-需求分析与优先级.md#42-v10-明确不做什么写清楚比写什么更重要)。

## 2. 用户角色与权限

| 角色 | 定义 | 权限 |
|------|------|------|
| 个人用户 | 注册即用，免费 | 话术生成、异议库、邮件助手、个人收藏、效果标记 |

## 3. 术语表

## 4. 功能需求

### FR-001 场景话术生成（P0 · 核心）

**用户故事**：作为一名销售，我要在见客户前输入客户场景，以便 5 分钟内拿到一份可直接使用的作战方案。

**主流程**：用户选择场景参数（4 项，其中 3 项必选）→ 系统校验 → 流式生成 → 展示作战方案（五大模块）→ 用户复制 / 换一版 / 收藏 / 标记。

**作战方案结构（生成结果定义）**：

| 模块 | 内容要求 | 字数约束 |
|------|---------|---------|
| ① 开场白 | 匹配行业语境的破冰话术，含 1 个具体细节钩子 | ≤ 100 字 |
| ② 提问框架 | 3 个递进式问题（现状→痛点→期望），体现 SPIN 逻辑 | 每问 ≤ 40 字 |
| ③ 价值主张 | 结合行业 + 角色的差异化价值陈述，含 1 个量化锚点 | ≤ 150 字 |
| ④ 异议预案 | 预判该场景 Top 2 异议，各给 1 句应对金句 | 每条 ≤ 60 字 |
| ⑤ 下一步行动 | 1 个明确的具体推进动作（含时间承诺话术） | ≤ 50 字 |

**字段定义（请求参数）**：

| 字段 | 类型 | 必填 | 枚举值 |
|------|------|:---:|--------|
| industry | string | 是 | 制造业 / SaaS软件 / 金融 / 医疗 / 教育培训 / 贸易零售 / 其他 |
| role | string | 是 | 决策者 / 影响者 / 使用者 |
| stage | string | 是 | 初次接触 / 需求挖掘 / 方案演示 / 异议处理 / 谈判成交 |
| goal | string | 否 | 自由文本，≤ 50 字，如「约到第二次会议」 |

**异常与边界**：

- `goal` 含敏感词（涉政、违禁）→ 过滤后生成，不提示用户
- 参数组合样本少（历史生成量 < 20 次）→ 结果顶部黄条提示「该场景组合样本较少，结果仅供参考」
- 生成超时 15s → 降级模板 + Toast「网络繁忙，已切换极速模式」，事件上报 `generate_degrade`

**验收标准**：

- Given 用户已选择 3 项必选参数，When 点击生成，Then 5s 内出现流式输出且 P95 15s 内完成
- Given 用户点击「换一版」，When 重新生成，Then 新结果与上一版重复度 < 30%（模块级对比）
- Given 生成服务连续失败，When 用户第三次点击生成，Then 展示降级模板且历史参数保留
- Given 用户复制任一模块，When 复制成功，Then Toast 提示且上报 `module_copy` 事件

### FR-002 异议应对库（P0）

**用户故事**：作为一名销售，当客户当场提出异议时，我要快速查到应对策略，以便不慌不乱地推进对话。

**内容结构**：12 类高频异议（价格贵 / 再考虑 / 已有供应商 / 要汇报领导 / 暂无预算 / 需要试用 / 效果存疑 / 竞品比较 / 更换成本 / 团队反对 / 时机不对 / 个人顾虑），每类异议包含：

- **五步应对法**：认同（先接住情绪）→ 探究（问出真实原因）→ 重构（换个角度定义问题）→ 证据（案例 / 数据 / 逻辑支撑）→ 推进（给一个小承诺动作）
- 2 个话术示例（不同语气：强势单刀 / 温和顾问）
- 适用场景标签（行业 / 阶段）

**验收标准**：

- Given 用户在搜索框输入「贵」，When 输入完成，Then 300ms 内展示「价格贵」异议卡（前端本地索引）
- Given 用户无网络，When 打开异议库，Then 展示本地缓存的 Top 3 高频异议并标注「离线内容」
- 每条异议内容需通过内容评审（业务专家 1 名 + 编辑 1 名）后才可上线

### FR-003 跟进邮件助手（P0）

**用户故事**：作为一名销售，会后我要快速发出得体的跟进邮件，以便把 30 分钟的写作时间省下来。

**输入**：客户称呼、沟通要点（≤ 200 字，自由文本）、语气（专业正式 / 亲切自然 / 简洁干练）。

**输出**：邮件主题（≤ 20 字）+ 正文（结构：感谢与回顾 → 双方共识 → 价值强化 → 明确下一步，全篇 ≤ 300 字）。

**验收标准**：

- Given 用户填写要点并选择语气，When 点击生成，Then 输出符合四段结构且字数达标
- Given 用户点击「重新生成」，When 连续 3 次，Then 至少 2 次开篇句式不同
- 草稿每 10s 自动保存至本地，刷新不丢失

### FR-004 个人收藏夹与历史记录（P1）

- 收藏以「作战方案」为单位，支持自定义命名（默认取场景参数拼接）
- 历史记录保留最近 100 条，含生成时间、场景参数、效果标记状态
- 支持按场景参数筛选历史记录

### FR-005 效果标记（P1 · 数据闭环基础）

**用户故事**：作为一名销售，我用某版话术谈完客户后，我要标记它的效果，以便下次复用有效的打法。

**规则**：

| 标记状态 | 触发时机 | 说明 |
|---------|---------|------|
| 用了 | 用户主动标记 | 生成后 72h 内可标记，超时入口隐藏 |
| 有效 | 在「用了」基础上追加 | 单选：有效 / 无效 |
| 成交 | 关联该场景成单 | 由用户手动触发，赠送 20 次生成额度（激励设计） |

**验收标准**：Given 某方案已被标记「成交」，When 用户查看历史记录，Then 该记录展示「🏆」标识且置顶可搜

## 5. 全局规则

1. **账号体系**：手机号 + 验证码登录，未登录可浏览异议库（只读 3 条），核心功能登录后使用
2. **生成额度**：免费用户每日 20 次生成（话术 + 邮件共享额度），当日 24:00 重置；剩余 3 次时提示
3. **内容安全**：所有生成结果经过敏感词过滤（双库：平台级 + 行业级），命中则重新生成一次，二次命中转人工审核队列

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面首屏 ≤ 2s；生成 P95 ≤ 15s（流式输出首字 ≤ 5s）；异议库搜索 ≤ 300ms |
| 兼容 | 主流浏览器最近两个大版本；移动端 H5 自适应（375px 宽度基准） |
| 可用性 | 核心服务 99.5%；生成服务异常时降级模板兜底，**不允许出现空白结果页** |
| 安全 | 传输 HTTPS；用户输入不落原始日志，生成记录脱敏存储；详见[技术方案 §6](./06-技术方案与内部设计.md#6-安全与合规设计) |
| 合规 | 生成内容显著标识「AI 生成」；用户协议明示数据处理方式 |

## 7. 埋点方案

| 事件名 | 触发时机 | 关键参数 | 用途 |
|--------|---------|---------|------|
| `generate_start` | 点击生成 | 参数四元组 | 统计场景分布 |
| `generate_complete` | 生成完成 | 耗时 / 是否降级 | 性能监控 |
| `generate_degrade` | 触发降级 | 失败原因 | 服务质量告警 |
| `module_copy` | 复制模块 | 模块类型 | **采纳率（北极星辅助）** |
| `generate_regenerate` | 换一版 | 第几次 | 质量信号（连续换版 = 结果差） |
| `objection_view` | 查看异议 | 异议类型 | 内容热度 |
| `feedback_mark` | 效果标记 | 三态 | 话术-效果配对数据（V1.5 团队库的数据基础） |
