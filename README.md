## 📌 这是什么

这是一个**完整的产品经理作品集项目**：以「B2B 销售团队的 AI 赋能」为命题，覆盖从用户调研、需求分析、产品路线规划、用户流程设计、PRD 撰写，到面向研发的内部技术方案的全流程，并附带一个**可直接打开交互的原型 Demo**。

> 📌 **关于本项目**：这是一个个人能力展示作品集。我在过程中按真实产品经理的工作方法（用户调研 → 需求分析 → 路线规划 → PRD → 技术方案）完成了完整链路。文中展示的人物访谈与数据为案例设定，目的是连贯呈现完整的产品决策过程——而非声称这是一个已上线的真实产品。

## 🎯 为什么做这个产品

**三个真实存在的行业痛点：**

1. **新人成长慢**：B2B 销售新人平均需要 3 个月以上才能独立谈单，Top Sales 的经验依赖口口相传，无法沉淀；
2. **异议处理没章法**：客户异议（"太贵了""再考虑"）是丢单的首要原因，但多数销售靠临场发挥；
3. **跟进效率低**：销售日均花费 1 小时以上写跟进邮件、翻话术资料，时间没有花在客户身上。

**产品定位**：轻量级 AI 销售助手，切入「场景化话术生成 + 异议应对 + 跟进邮件」三个高频刚需场景，让每个销售在见客户前 5 分钟内拿到一份可用的作战方案。

## 🎮 原型 Demo

`demo/index.html` 是一个**零依赖、单文件可交互原型**，本地双击即可打开：

- **场景话术生成**：选择行业 / 客户角色 / 沟通阶段 / 本次目标 → 生成完整作战方案（开场白、提问框架、价值主张、下一步行动）
- **异议应对教练**：五步应对法（认同 → 探究 → 重构 → 证据 → 推进），支持输入任意自定义异议
- **跟进邮件助手**：输入沟通要点 → 生成结构化跟进邮件

> Demo 内置本地规则引擎，开箱即可演示。点击顶部「🔌 本地演示 · 点击切换」可启用真实 LLM（DeepSeek）——**话术生成 / 异议应对 / 跟进邮件三个功能均支持真实 AI 生成**，首次需输入自己的 API key（仅保存在浏览器本地，不上传服务器）。
>
> 接口设计已在[技术方案 §5.1 原型实况对照](./docs/06-技术方案与内部设计.md#51-原型实况对照v0-demo--已落地)中说明，完整生产架构见 §5。
